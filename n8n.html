Part 1 — Introduction & Core Concepts

What is n8n?

🔁
n8n in one sentence n8n (pronounced "n-eight-n") is an open-source workflow automation platform that lets you connect any app, API, or AI model through a visual drag-and-drop interface — like Zapier, but free, self-hostable, and AI-first.

🧩

Core Building Blocks

  • Nodes — Individual action/logic units (Gmail, HTTP, LLM)
  • Connections — Arrows linking nodes (data flows through)
  • Workflows — A complete automation (collection of nodes)
  • Triggers — What starts the workflow (webhook, schedule, email)
  • Expressions — Dynamic values: {{ $json.email }}
  • Credentials — API keys stored securely
🤖

AI Nodes in n8n

  • AI Agent — Full ReAct agent with tools
  • Basic LLM Chain — Simple prompt → response
  • AI Chat — Conversational interface trigger
  • Embeddings — Generate text embeddings
  • Vector Store — Store & retrieve with Chroma/Pinecone
  • Memory Buffer — Conversation memory
  • Tool nodes — Web search, calculator, code
🌐

400+ Integrations

  • 📧 Gmail, Outlook, SMTP
  • 💬 Slack, Telegram, WhatsApp
  • 📁 Google Drive, Dropbox, OneDrive
  • 🗄️ MySQL, PostgreSQL, MongoDB
  • 📋 Notion, Airtable, Google Sheets
  • 🤖 OpenAI, Anthropic, Ollama, Groq
  • 🔗 HTTP Request (any REST API)
⚡

Trigger Types

  • Webhook — Triggered by HTTP POST from external app
  • Schedule — Run every X minutes/hours/days (cron)
  • Email — Triggered when email arrives
  • Chat Message — AI chat interface built-in
  • Form Submission — n8n hosted form trigger
  • Manual — Click button to run (testing)
🔤

n8n Expressions

Access data from previous nodes dynamically:

  • {{ $json.fieldName }} — current node data
  • {{ $('NodeName').item.json.field }} — specific node
  • {{ $now.toISO() }} — current timestamp
  • {{ $input.all() }} — all input items
  • {{ $vars.myVariable }} — workflow variables
🔧 Installation & Setup
💻

3 Ways to Install n8n

Choose the method that suits your system best

A

Method 1 — npm (Recommended for workshop)

bash Terminal 
# Install n8n globally
npm install -g n8n

# Start n8n
n8n start

# Open in browser
# http://localhost:5678
B

Method 2 — Docker (Clean, isolated)

bash Terminal 
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  docker.n8n.io/n8nio/n8n

# Open http://localhost:5678
C

Method 3 — n8n Cloud (Instant, no install)

Go to n8n.io → Sign up free → Get a cloud instance instantly. Free trial available. Best if your laptop has limited RAM.

D

Connect Ollama to n8n

In n8n, go to Settings → Credentials → Add Credential → Ollama

Base URL http://localhost:11434
💡
Make sure Ollama is running! Start Ollama first: ollama serve — then n8n can connect to it as an LLM provider.
🖥️ n8n Interface Quick Guide
🗺️

Canvas (Main Area)

  • Drag-and-drop workspace for building workflows
  • Right-click → Add Node to insert a new node
  • Drag connections from node output dots
  • Click a node to configure it
  • Ctrl+A to select all, Delete to remove
📚

Node Library (Left Panel)

  • Search 400+ nodes by name or category
  • Categories: Triggers, Actions, AI, Transform, Flow
  • Drag directly onto canvas
  • Favorites: pin commonly used nodes
▶️

Execution & Testing

  • Test Workflow — Run manually, see all data
  • Execute Node — Test single node in isolation
  • Click any node after run → see Input/Output data
  • Executions tab — history of all runs
  • Pin data — freeze test data to avoid re-fetching
⚙️

Workflow Settings

  • Active toggle — enable/disable automation
  • Variables — global workflow constants
  • Error workflow — run another workflow on failure
  • Timezone — for scheduled triggers
  • Save & Share — export as JSON
🎯
How to import workshop workflows Each project below includes a JSON workflow. To import: Open n8n → Click + (New Workflow) → Menu (⋯) → Import from File/URL → Paste the JSON → Click Import. All nodes will appear on canvas ready to configure.

🚀 Bonus: n8n Advanced Tips
🔁

Error Handling

  • Add a "Error Trigger" workflow for failures
  • Use Try/Catch pattern with IF nodes
  • Set continueOnFail: true for non-critical nodes
  • Log errors to Google Sheets automatically
🔀

Loop Processing

  • Use Loop Over Items node for lists
  • Process each email, article, or record individually
  • Set batch size to control API rate limits
  • Use Wait node to add delays between iterations
🔐

Security Best Practices

  • Store all API keys in Credentials (never hardcode)
  • Use webhook authentication (header token)
  • Limit webhook to specific IP ranges if possible
  • Use environment variables for sensitive config
⚡

Performance Tips

  • Pin test data to avoid re-fetching APIs during dev
  • Use Merge node to combine parallel branches
  • Set appropriate execution timeouts for LLM nodes
  • Use Cache node for repeated API calls
