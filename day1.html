Introduction to Generative AI & LLMs

🕘 9:00 – 11:00 AM
📖 Core Concepts
💡
Intuitive Analogy — LLM vs AI Agent A standard Chatbot functions like an intelligent text generator that responds when prompted. In contrast, an AI Agent 🤖 acts as an autonomous digital worker equipped with tools, memory, and reasoning loops to accomplish multi-step objectives independently.
🧠

AI vs ML vs Deep Learning

Understanding the hierarchy of intelligence systems:

  • AI — any technique making machines smart (rules, logic)
  • ML — machines learn from data (linear regression, decision trees)
  • Deep Learning — neural networks with many layers
  • Gen AI — models that generate new content (text, images, code)
📈

Evolution of LLMs

The rapid progression of language models:

  • 2017 — "Attention is All You Need" paper (Transformers)
  • 2018 — BERT by Google (bidirectional)
  • 2019 — GPT-2 by OpenAI
  • 2022 — ChatGPT launches (GPT-3.5)
  • 2023 — Llama, Mistral (open-source)
  • 2024 — Llama 3, GPT-4o, Claude 3
⚙️

How Transformers Work

The core architecture powering all modern LLMs:

  • Tokenization — text split into tokens (words/subwords)
  • Embeddings — tokens converted to number vectors
  • Attention — model learns which tokens relate to each other
  • Feed Forward — dense layers process attention output
  • Output — predicts next token, repeat until done
✍️

Prompt Engineering

Techniques to get better responses from LLMs:

  • Zero-shot — Ask directly: "Translate to French: Hello"
  • Few-shot — Give examples before asking
  • Chain-of-Thought — "Think step by step…"
  • System Prompt — Define role/persona for the AI
  • Temperature — Controls randomness (0=deterministic)

What is Agentic AI?

An AI Agent = LLM + Tools + Memory + Planning

  • LLM — the brain (reasoning)
  • Tools — web search, calculator, APIs
  • Memory — remember past conversations
  • Planning — break tasks into steps
  • Example: "Research topic X and write a report" → agent searches, reads, writes
💡
Key Insight for Interviews The difference between a Chatbot and an AI Agent: A chatbot only responds. An agent can take actions — search the web, write files, run code, and make decisions autonomously.

# Day 1 - Session 1: Your First AI Chatbot
import requests
import json

# Ollama runs locally on port 11434
OLLAMA_URL = "http://localhost:11434/api/generate"
MODEL = "llama3.2"

def ask_ai(message, history=[]):
    """Send a message to Llama 3.2 and get a response"""
    
    # Build conversation context
    context = ""
    for msg in history[-4:]:  # last 4 exchanges
        context += f"User: {msg['user']}\nAssistant: {msg['ai']}\n"
    
    full_prompt = f"""{context}User: {message}\nAssistant:"""
    
    response = requests.post(OLLAMA_URL, json={
        "model": MODEL,
        "prompt": full_prompt,
        "stream": False,
        "options": {"temperature": 0.7, "num_predict": 500}
    })
    
    return response.json()["response"]

def main():
    print("🤖 AI Chatbot powered by Llama 3.2 (type 'quit' to exit)")
    print("-" * 50)
    
    history = []
    
    while True:
        user_input = input("\nYou: ").strip()
        
        if user_input.lower() in ['quit', 'exit', 'bye']:
            print("Goodbye! 👋")
            break
        
        if not user_input:
            continue
        
        print("AI: Thinking...", end="\r")
        response = ask_ai(user_input, history)
        print(f"AI: {response}")
        
        history.append({"user": user_input, "ai": response})

if __name__ == "__main__":
    main()

LangChain Fundamentals

🕑 11:15 AM – 1:00 PM
📖 Core Concepts
💡
Intuitive Analogy — LangChain Framework Think of LangChain as a modular AI design system. Instead of writing complex custom code, you connect pre-built components—Prompts, LLM Models, Tools, and Output Parsers—into robust end-to-end applications.
🔗
What is LangChain? LangChain is a Python framework for building LLM-powered applications. It connects LLMs with prompts, memory, tools, and data sources through a unified interface — making it the #1 most used AI framework in production.
🏗️

LangChain Architecture

Six core building blocks:

  • Models — LLM/Chat model wrappers
  • Prompts — PromptTemplate, ChatPromptTemplate
  • Chains — Connect components with | pipe
  • Memory — Store conversation history
  • Tools — External capabilities (search, calc)
  • Agents — LLM decides which tool to use
📝

Prompt Templates

Templates let you create reusable prompts with dynamic variables:

  • PromptTemplate — simple string templates
  • ChatPromptTemplate — for chat models (system + human)
  • Variables use {curly_braces} syntax
  • Can include few-shot examples
⛓️

LCEL — Pipe Syntax

LangChain Expression Language uses | to chain components:

  • prompt | llm | parser
  • Each component's output → next component's input
  • Easy to read, debug, and modify
  • Supports parallel execution
📤

Output Parsers

Parse LLM text output into structured formats:

  • StrOutputParser — returns clean string
  • JsonOutputParser — parses JSON response
  • PydanticOutputParser — validates with data model
  • CommaSeparatedListOutputParser
🧠

Memory

Enable conversations by remembering previous messages:

  • ConversationBufferMemory — stores all messages
  • ConversationBufferWindowMemory — last N messages
  • ConversationSummaryMemory — LLM summarizes history
🔄

LangChain Pipeline Flow

Input → PromptTemplate → ChatOllama → OutputParser → Result

All connected using LCEL pipe | syntax

prompt = ChatPromptTemplate.from_messages([
    ("system", """You are an expert HR recruiter and career coach 
    with 10+ years of experience. Analyze the given resume and provide 
    structured, honest, and actionable feedback."""),
    ("human", """
    Please review this resume and provide:
    
    **SCORE:** Give an overall score out of 10
    
    **STRENGTHS** (top 3):
    - Point 1
    - Point 2  
    - Point 3
    
    **AREAS TO IMPROVE** (top 3):
    - Point 1
    - Point 2
    - Point 3

    {resume}

Retrieval Augmented Generation (RAG)

🕑 2:00 – 5:00 PM
📖 Core Concepts
💡
Intuitive Analogy — RAG & Vector Search A Vector Database indexes data by semantic meaning rather than keyword matches. RAG provides the LLM with an open-book retrieval system—searching your documents for authoritative context before generating factual answers.
❓
The Problem RAG Solves LLMs have a training cutoff — they don't know about your college handbook, recent news, or your private documents. Asking GPT about your university's exam policy? It will hallucinate. RAG fixes this by letting the model "read" your documents first.
🔢

What are Embeddings?

Embeddings convert text into numerical vectors (lists of numbers) that capture meaning:

  • "King" and "Queen" have similar vectors
  • "Cat" and "Dog" are closer than "Cat" and "Car"
  • Similarity is measured by cosine distance
  • We use nomic-embed-text model via Ollama
🗃️

Vector Databases

Specialized databases that store and search embeddings:

  • ChromaDB — local, no setup required ✅
  • Pinecone — cloud-based, scalable
  • FAISS — Facebook's fast similarity search
  • Search finds similar vectors (not exact keyword match)
✂️

Text Splitting

Large documents must be split into chunks before embedding:

  • chunk_size=500 — characters per chunk
  • chunk_overlap=50 — overlap prevents cutting mid-sentence
  • Too large → loses precision
  • Too small → loses context
🔄

Full RAG Pipeline

📄 Load Documents ↓ ✂️ Split into Chunks ↓ 🔢 Create Embeddings ↓ 🗃️ Store in ChromaDB ↓ ❓ User Asks Question ↓ 🔍 Retrieve Relevant Chunks ↓ 🤖 LLM Generates Answer

# Day 1 - Session 3: College Question Answering System (RAG)
import os
from langchain_community.document_loaders import PyPDFLoader, TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_chroma import Chroma
from langchain_ollama import OllamaEmbeddings, ChatOllama
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

# ── Configuration ──
MODEL = "llama3.2"
EMBED_MODEL = "nomic-embed-text"
CHROMA_PATH = "./chroma_db"
CHUNK_SIZE = 500
CHUNK_OVERLAP = 50

def load_documents(file_path: str):
    """Load PDF or text file"""
    print(f"📄 Loading document: {file_path}")
    
    if file_path.endswith('.pdf'):
        loader = PyPDFLoader(file_path)
    else:
        loader = TextLoader(file_path)
    
    docs = loader.load()
    print(f"✅ Loaded {len(docs)} page(s)")
    return docs

def split_documents(docs):
    """Split documents into smaller chunks"""
    print("✂️  Splitting into chunks...")
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=CHUNK_SIZE,
        chunk_overlap=CHUNK_OVERLAP,
        separators=["\n\n", "\n", " ", ""]
    )
    chunks = splitter.split_documents(docs)
    print(f"✅ Created {len(chunks)} chunks")
    return chunks

def create_vector_db(chunks):
    """Create and persist ChromaDB vector store"""
    print("🔢 Creating embeddings and storing in ChromaDB...")
    embeddings = OllamaEmbeddings(model=EMBED_MODEL)
    vectordb = Chroma.from_documents(
        documents=chunks,
        embedding=embeddings,
        persist_directory=CHROMA_PATH
    )
    print("✅ Vector database created!")
    return vectordb

def load_vector_db():
    """Load existing ChromaDB"""
    embeddings = OllamaEmbeddings(model=EMBED_MODEL)
    return Chroma(
        persist_directory=CHROMA_PATH,
        embedding_function=embeddings
    )

def build_rag_chain(vectordb):
    """Build the RAG question-answering chain"""
    llm = ChatOllama(model=MODEL, temperature=0)
    retriever = vectordb.as_retriever(
        search_type="similarity",
        search_kwargs={"k": 3}  # retrieve top 3 chunks
    )
    
    prompt = ChatPromptTemplate.from_messages([
        ("system", """You are a helpful assistant for answering questions 
        about college documents. Use ONLY the provided context to answer.
        If the answer is not in the context, say "I don't have that information 
        in the provided documents."
        
        Always mention which part of the document your answer comes from."""),
        ("human", """Context from documents:
        {context}
        
        Question: {question}
        
        Answer (with source reference):""")
    ])
    
    def format_docs(docs):
        return "\n\n".join([
            f"[Source: Page {doc.metadata.get('page', 'N/A')}]\n{doc.page_content}"
            for doc in docs
        ])
    
    chain = (
        {"context": retriever | format_docs, "question": RunnablePassthrough()}
        | prompt
        | llm
        | StrOutputParser()
    )
    return chain

def main():
    print("🏫 College Q&A System (RAG)")
    print("=" * 45)
    
    # Check if DB exists, else create it
    if not os.path.exists(CHROMA_PATH):
        pdf_path = input("Enter path to your PDF/TXT file: ").strip()
        if not os.path.exists(pdf_path):
            print("File not found! Creating demo with sample text...")
            # Create sample text file for demo
            with open("college_info.txt", "w") as f:
                f.write("""
Jyothy Institute of Technology - College Handbook

EXAMINATION RULES:
Students must carry their hall ticket to all examinations.
Mobile phones are strictly prohibited in examination halls.
Minimum 75% attendance is required to appear for exams.
Students found cheating will be expelled from the examination.

ATTENDANCE POLICY:
Regular attendance is mandatory for all students.
Students with less than 75% attendance will be detained.
Medical leave requires a medical certificate from a registered doctor.
Prior permission must be obtained for planned absences.

FEE STRUCTURE:
Tuition fee: Rs. 80,000 per year
Hostel fee: Rs. 60,000 per year (including meals)
Lab fee: Rs. 5,000 per semester
Bus facility available for selected routes.

LIBRARY RULES:
Library hours: 8:00 AM to 8:00 PM on working days
Students can borrow up to 3 books at a time
Books must be returned within 14 days
Late fee: Rs. 2 per day per book

PLACEMENT CELL:
The Placement Cell coordinates campus recruitment.
Students with CGPA above 6.0 are eligible for placement.
Mock interviews and aptitude training provided.
Companies visiting include TCS, Infosys, Wipro, Accenture.
                """)
            pdf_path = "college_info.txt"
        
        docs = load_documents(pdf_path)
        chunks = split_documents(docs)
        vectordb = create_vector_db(chunks)
    else:
        print("📂 Loading existing database...")
        vectordb = load_vector_db()
    
    chain = build_rag_chain(vectordb)
    
    print("\n🎉 Ready! Ask questions about the college documents.")
    print("Type 'quit' to exit.\n")
    
    while True:
        question = input("❓ Your question: ").strip()
        if question.lower() in ['quit', 'exit']:
            break
        if not question:
            continue
        
        print("\n🤖 Answer:")
        answer = chain.invoke(question)
        print(answer)
        print("\n" + "-" * 45 + "\n")

if __name__ == "__main__":
    main()
